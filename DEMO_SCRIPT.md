# Tech Fest Demo Script (3–5 minutes)

**Opening (30 seconds)**  
“Students often search through many notices and PDFs to find one answer. CampusMate AI brings approved college information into one bilingual assistant.”

**Student view (60 seconds)**  
1. Open the Home page.
2. Ask “Where can I find study materials?”
3. Ask “പരീക്ഷാ തീയതികൾ എവിടെ ലഭിക്കും?”
4. Point out that answers show the sources used and that the system admits when no relevant record is available.

**Admin view (60–90 seconds)**  
1. Open Admin and sign in.
2. Publish a clearly labelled demo notice.
3. Upload a text-based PDF or TXT file with a few facts, for example:
   “BCA Web Technology demo workshop: 24 November 2026, Lab 2. This is sample data for the demonstration only.”
4. Return to Ask AI and ask “When is the demo workshop?” Show the source label.

**Technical explanation (45 seconds)**  
“The app extracts document text, splits it into overlapping chunks, retrieves relevant chunks using character n-gram TF-IDF, and constructs an answer from those retrieved passages. It supports both English and Malayalam script matching without sending college documents to an external API.”

**Close (30 seconds)**  
“Future scope includes voice input, better multilingual embeddings, answer synthesis with a language model and citations, student login, and integration with verified college systems.”

**Before the event:** replace all placeholders with approved data, test the exact PDFs, change the admin password, and keep a backup copy of your demo documents.
